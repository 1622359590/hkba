# HKBA 新闻动态页面改版设计

日期：2026-08-02  
状态：前台视觉与后台组件同步方案已确认，待规格审阅

## 1. 目标

将现有新闻动态页从“大面积空 Hero + 等权卡片网格”升级为具有区块链技术气质的机构级新闻页面。页面应同时满足：

- 第一眼具有高级、克制的科技感；
- 最新和最重要的新闻拥有清晰焦点；
- 即使新闻缺少封面图，页面仍有稳定、完整的视觉表现；
- 保留现有新 API 优先、旧 API 回退、年份与分类筛选、分页和中英双语能力；
- 让后台编辑人员能够配置首屏文案、焦点来源、次要新闻数量、年份与分类筛选，并在 Studio 中看到与前台一致的组件预览；
- 在桌面、平板和手机上保持清晰的信息层级与可访问交互。

## 2. 视觉方向

采用已确认的 A「旗舰报道」方向，延续全站深色科技主题，但减少普通玻璃卡片堆叠感。科技感来自有意义的信息层和精确秩序，不依赖高饱和渐变或过量光效。

### 2.1 首屏标题区

首屏采用左右不对称构图：

- 左侧依次显示英文眉题、中文主标题和简短说明；
- 右侧以低对比度节点网络表达香港、HKBA、全球和大湾区之间的连接；
- 右上角显示香港坐标和 `NETWORK ONLINE` 状态；
- 右下角显示紧凑的 `ECOSYSTEM PULSE` 状态组件；
- 首屏底部加入数据轨道，展示新闻数量、合作网络或内容更新时间等信息；
- 背景使用局部网格、径向冷光和细线，所有装饰均不得影响标题对比度。

标题区不使用大按钮。页面下方已经紧接新闻内容，不需要“查看最新消息”这类重复跳转操作。

### 2.2 新闻焦点区

标题区下方直接进入“协会新闻与行业观察”：

- 左侧为最新一条或当前列表第一条新闻，占据主视觉；
- 右侧垂直排列后续两条新闻；
- 有封面时显示真实封面；
- 无封面时显示基于 CSS 的抽象节点、链路和微光背景，不使用外部随机占位图；
- 焦点新闻显示分类、日期、标题和摘要，整块可点击；
- Hover 仅使用图片轻微放大、边线变亮和箭头位移，避免夸张浮动。

## 3. 列表与筛选

焦点区之后展示剩余新闻，使用两列编辑式列表而不是三列等高卡片：

- 每条新闻由序号或年份、日期、分类、标题、摘要和进入箭头组成；
- 桌面端两列，窄屏单列；
- 标题最多两行，摘要最多三行；
- 列表项之间以细分割线建立节奏，减少厚重卡片边框；
- 已在焦点区出现的前三条新闻不在列表中重复。

筛选区与栏目标题处于同一视觉带：

- 年份和分类分成两个语义清晰的控件组；
- 桌面端可横向排列，移动端允许横向滚动或自然换行；
- 当前选项使用青色实底或高对比描边；
- 筛选和翻页时保留已有数据直至新结果返回，并显示轻量加载状态，避免页面整体闪空。

## 4. 组件边界

页面拆分为以下小组件，放在专用新闻组件目录，并由传统回退页、已发布页面渲染器和 Studio 预览共同复用：

- `NewsHero`：标题、网络图形、状态和数据轨道；
- `NewsFilters`：年份、分类和旧数据分类筛选；
- `FeaturedNews`：一主两次的焦点新闻布局；
- `NewsFeed`：剩余新闻的编辑式列表；
- `NewsArtwork`：无封面时的抽象技术图形；
- `NewsPagination`：保留现有分页行为并统一视觉状态。
- `PublishedNewsExperience`：读取已发布的新闻页面组件树，协调查询、筛选、焦点选择和分页；
- `StudioNewsPreview`：把 Studio 当前草稿配置和已加载的公开新闻数据传给同一组展示组件。

新、旧两套数据在渲染前转换为统一的页面展示模型，至少包含：

```ts
type NewsViewItem = {
  id: string;
  href: string;
  title: string;
  summary: string;
  category: string;
  date: string;
  year?: number;
  image?: { src: string; alt: string };
};
```

这样可以避免为新 API、旧 API、已发布页面和 Studio 预览维护多套重复 JSX，同时保持现有回退逻辑不变。

## 5. 数据流与状态

1. `PublicPageSwitch` 先请求 `/news` 的已发布组件树。
2. 有已发布组件树时，`PublishedNewsExperience` 读取 `content.hero`、`news.featured`、`news.category-tabs` 和 `news.list` 的内容与设置。
3. 没有已发布组件树时，继续渲染 `NewsListClient`，并保留新 API 优先、旧 API 回退的现有行为。
4. `PublishedNewsExperience` 根据列表组件的年份模式、栏目范围、每页数量和排序建立新闻查询；访客选择年份或分类后重新请求公开新闻 API。
5. 原始数据根据当前语言转换为 `NewsViewItem[]`。
6. 焦点来源为 `auto` 时选择当前查询的最新新闻；来源为 `pinned` 时按后台指定顺序解析新闻，失效项目依据 `fallbackToLatest` 设置回退。
7. 焦点区使用一条主新闻和后台配置数量的次要新闻；所有焦点新闻从 `NewsFeed` 中排除。
8. 数据返回后原子更新焦点区、列表和总数，防止不同区域显示不同查询结果。

任何展示性的统计文案必须来自真实可获得的数据。无法获得合作伙伴数或区域数时，数据轨道只显示新闻总数、当前年份、内容类别数和最近更新时间，不伪造业务数据。

## 6. 加载、空状态与错误状态

- 首次加载：显示与最终结构一致的标题区和新闻骨架；
- 筛选加载：筛选控件进入忙碌状态，新闻区域保留旧内容并降低透明度；
- 错误：沿用现有错误提示和重试能力，错误区置于筛选下方；
- 空状态：使用轻量节点图形、明确说明和“联系协会”入口；
- 图片失败：自动切换为 `NewsArtwork`，不得留下破图图标；
- 无分类或年份数据：隐藏对应筛选组，不显示空控件。

## 7. 响应式与可访问性

- 大于 1024px：完整左右首屏、主次新闻分栏、两列新闻列表；
- 641–1024px：网络图形降低对比度并后移，焦点新闻可保持分栏或按内容宽度切为纵向；
- 小于等于 640px：标题单列，状态组件精简，主次新闻和列表全部单列；
- 所有新闻块使用语义化 `article` 和可聚焦链接；
- 装饰 SVG 使用 `aria-hidden="true"`；
- 图片使用新闻数据中的双语替代文本，旧数据封面使用新闻标题作为替代文本；
- 筛选按钮保留可见焦点环、`aria-pressed` 和忙碌/禁用状态；
- 动效遵循 `prefers-reduced-motion`，关闭位移和连续脉冲。

## 8. 样式与动效

- 页面专属样式放入独立样式文件并由全局样式入口导入，移除新闻页主要内联样式；
- 使用现有 `--bg`、`--surface-*`、`--text-*`、`--cyan` 和 motion token；
- 青色为唯一强调色，蓝色只用于背景深度，不增加紫色或金色；
- 节点网络为静态 SVG，可选一次性淡入，不做持续高成本动画；
- 卡片和列表交互只改变 `transform`、`opacity`、边框和背景；
- 页面进入使用短距离、分组错峰淡入，时长控制在 600ms 内。

## 9. 后台组件同步

不新增重复的全包式新闻门户组件。升级现有组件注册表并继续使用现有字段校验、页面草稿、发布和版本机制。

### 9.1 组件变体

- `content.hero` 新增 `network-news` 变体；标题、副标题仍使用现有双语内容字段，按钮在该变体下不显示；
- `news.featured` 新增 `flagship` 变体；保留 `auto`、`pinnedIds`、`secondaryCount` 和 `fallbackToLatest`；
- `news.list` 新增 `editorial` 变体；保留 `yearMode`、`year`、`categoryIds`、`tagIds`、`pageSize`、`showSummary` 和 `showDate`；
- `news.category-tabs` 新增 `technology` 变体，并增加 `showYearFilter`、`showCategoryFilter` 和 `maxTabs` 控件。

注册表继续存储查询条件，不复制新闻标题、摘要或正文。所有新枚举值必须经过组件定义验证，并能由通用属性表单编辑。

### 9.2 Studio 预览

- Studio 使用已经加载的公开新闻数据预览焦点区和列表；
- 首屏、焦点、列表和筛选必须复用前台组件，不在 Studio 内复制另一套布局；
- 画布内链接阻止导航，但保留 Hover、焦点层级和响应式结构；
- `pinned` 项不在预览数据中时显示明确的回退提示，不伪造新闻；
- 修改双语文案、变体、次要数量和显示开关后，画布立即更新。

### 9.3 默认新闻页安全升级

- 新安装的 `/news` 默认页面使用 `network-news → flagship → technology → editorial` 组件序列；
- 现有页面只有在组件序列和核心文案仍与旧版系统默认值一致时才自动升级；
- 自动升级通过新草稿版本完成，不直接改写已发布版本；
- 已有自定义内容、额外组件或不同顺序的新闻页不自动修改，新变体仍可由编辑人员手动添加；
- 升级逻辑必须具备幂等性，多次启动不得重复插入组件。

### 9.4 公开查询支持

现有公开新闻列表查询继续支持年份、栏目、页码和每页数量。为完整解析 `pinnedIds`，公开数据层增加按 ID 批量读取已发布新闻的能力；只返回处于已发布状态的记录，并保持后台指定顺序。该能力扩展现有公开 API，不改变数据库结构。

## 10. 测试与验收

### 功能验收

- 新 API 有数据时正确显示筛选、焦点新闻、列表和分页；
- 新 API 无数据或失败时旧 API 新闻仍能显示；
- 中英文切换后标题、摘要、分类和日期语言正确；
- 年份、分类和页码切换不会重复或漏掉新闻；
- 新闻链接继续指向现有详情页地址；
- 图片加载失败后显示抽象图形；
- 已发布 `/news` 页面读取后台组件设置并正确组合首屏、焦点、筛选和列表；
- `pinned` 焦点按后台顺序显示，已撤回或不存在的新闻按配置回退；
- 焦点新闻不在编辑式列表中重复。

### 后台验收

- 组件定义接口返回四个新增变体及对应设置字段；
- Studio 修改首屏中英文文案、焦点来源、次要新闻数量、年份和分类设置后即时更新预览；
- 新安装生成完整的四组件新闻页；
- 旧版默认新闻页只创建一个升级草稿，重复运行不增加重复组件；
- 自定义新闻页不被自动改写；
- 按 ID 批量读取接口不会返回草稿或已撤回新闻。

### 视觉验收

- 1440px 桌面视口下首屏不再出现无意义的大面积空白；
- 主标题始终是首屏最高对比和最大的文本元素；
- 前三条新闻的主次关系一眼可见；
- 所有新闻无封面时页面仍然完整且有技术质感；
- 390px 手机视口无横向溢出，筛选、标题和新闻链接可正常使用；
- 键盘操作可访问所有筛选、新闻和分页控件；
- reduced-motion 环境没有持续闪烁、漂移或脉冲。

## 11. 不在本次范围内

- 不改新闻详情页；
- 不改后台新闻编辑和上传流程；
- 不新增第三方图标、动画或字体依赖；
- 不修改数据库结构；
- 不为视觉效果伪造合作伙伴、地区或链上数据。
