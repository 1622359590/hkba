# HKBA 后台浅色工作台与页面编辑体验设计

## 目标

将管理后台从低对比度深色界面调整为清晰、克制的浅灰白工作台，并让用户在工作室中能够直观编辑已经上线的页面。前台视觉保持不变。

## 视觉方向

- 浅灰色作为后台画布，白色作为导航、工具栏、面板和抽屉表面。
- 深灰文字承担主要信息，次级文字仍满足可读性；边框使用中性灰。
- 金色只用于发布、当前导航和关键操作；青绿色用于画布选中、输入焦点和信息状态。
- 阴影保持轻量，卡片圆角不超过现有设计系统的 12px。
- 主题变量限定在 `.admin-shell` 内，不能改变公开网站。

## 工作室交互

- 点击画布组件或组件结构中的条目时，同时选中组件并自动打开右侧属性抽屉。
- 通过键盘 Enter 选择结构条目时，行为与鼠标点击一致。
- 新增组件后保持自动选中，并打开属性抽屉。
- 页面顶部明确显示页面发布状态以及当前编辑状态。
- 对已发布页面显示“正在编辑草稿，线上版本不受影响；重新发布后更新”的说明。
- 未发布页面显示“尚未发布，发布后前台可见”。
- 保留现有草稿复制、自动保存、预览、发布确认和版本冲突机制。

## 异常与空状态

- 草稿载入失败继续显示现有错误横幅。
- 未选页面、无组件、未选组件保留明确操作入口。
- 选中组件后属性定义缺失时仍显示可理解的空状态，不阻断画布。

## 验收标准

- 后台所有主要页面呈浅色工作台，文字、表格、表单和按钮对比清晰。
- 前台页面颜色没有变化。
- 点击任意可编辑组件后，右侧属性抽屉立即打开。
- 已发布页面能创建或载入草稿，编辑提示不会暗示立即改动线上内容。
- `npm run build` 通过，桌面和窄屏后台无明显重叠或横向溢出。
