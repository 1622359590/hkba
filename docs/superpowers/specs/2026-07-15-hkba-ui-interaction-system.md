# HKBA UI 与交互规范

日期：2026-07-15
关联主设计：[HKBA 轻量页面构建后台总设计](./2026-07-15-hkba-lightweight-page-builder-design.md)

## 1. 视觉方向

后台采用“电影感深空”视觉语言：

- 大面积深色留白形成控制中心氛围。
- 金色用于 HKBA 品牌、主要发布动作和核心节点。
- 青色用于选择、连接、信息和系统运行状态。
- 玻璃面板只用于星系首页、浮层和短暂上下文，不在长表单中大量使用。
- 编辑工作区以清晰、低干扰和长时间可用为优先。

星系控制中心可以具有适度动态，页面工作室和新闻编辑器减少持续动画。

## 2. 设计令牌

建议基础颜色：

| 用途 | 颜色 |
| --- | --- |
| 页面背景 | `#05080E` |
| 深色表面 | `#08101A` |
| 提升表面 | `#0C1623` |
| 边框 | `rgba(148,163,184,0.14)` |
| 主文字 | `#DBE7F2` |
| 次文字 | `#8394A7` |
| 弱文字 | `#5F7287` |
| 品牌金 | `#D9B656` |
| 交互青 | `#67E8F9` |
| 成功 | `#86EFA8` |
| 警告 | `#F5D37B` |
| 错误 | `#FCA5A5` |

建议圆角：控件 8-10px，面板 14-18px，大容器 22-24px。阴影保持柔和，不能用高亮外发光代替边界和层级。

## 3. 字体与密度

- 正文使用系统无衬线字体栈，确保中文、英文和数字清晰。
- 星系状态标记可以使用等宽字体，但不用于长段正文。
- 页面标题 20-24px，面板标题 14-16px，正文 13-14px，辅助信息 11-12px。
- 交互目标最小 36×36px；主要按钮不低于 40px 高。
- 表单垂直间距统一，避免把大量字段压缩成密集终端界面。

## 4. 星系控制中心

### 4.1 节点

- 中心节点：HKBA 品牌核心。
- 一级节点：网站、内容、媒体、系统。
- 二级节点按需展开，不在初始画面同时显示全部页面。
- 点击节点聚焦并展开；双击或确认动作进入具体模块。
- 悬停显示名称、状态摘要和未处理数量。

### 4.2 状态

| 状态 | 表现 |
| --- | --- |
| 正常 | 青色细边和稳定弱光 |
| 存在草稿 | 金色点和草稿数量 |
| 待发布 | 金色环和发布图标 |
| 英文缺失 | 警告图标及 `EN` 数量 |
| 失败 | 红色图标、文字原因和重试入口 |
| 无权限 | 降低对比度并显示锁图标 |

所有状态包含文字或图标，不只使用颜色。

### 4.3 导航辅助

- 搜索可定位栏目、页面、新闻和系统模块。
- 鼠标滚轮缩放，拖动画布平移。
- 提供“返回核心”和面包屑。
- 键盘方向键在相邻节点移动，Enter 打开。
- 动画遵循系统“减少动态效果”设置。

## 5. 页面工作室

### 5.1 默认布局

- 顶栏：当前页面、保存状态、响应式宽度、预览、发布。
- 左侧图标栏：页面树、页面组件、组件库、媒体。
- 右侧图标栏：组件属性、页面设置、版本历史、发布检查。
- 中央：真实页面画布。

侧栏打开为覆盖式抽屉，不永久挤压画布。只有管理员固定面板时才允许画布缩窄，并记录个人偏好。

### 5.2 专注模式

- 隐藏左右图标栏和所有抽屉。
- 保留页面名称、宽度切换和退出入口。
- `Tab` 切换最近面板；`Esc` 关闭抽屉或退出专注模式。

### 5.3 组件选择和拖动

- 点击画布组件时显示轻量边框和组件名称，不使用大面积遮罩。
- 拖动时显示准确插入线和目标容器。
- 不允许拖入的位置显示原因，例如“标签页中不能再嵌套标签页”。
- 键盘用户可以通过“上移、下移、移至区段”完成同等操作。
- 拖动成功后立即自动保存结构草稿。

### 5.4 属性抽屉

- 顶部显示组件名称、类型和关闭入口。
- 字段按“内容、数据、显示、链接、可访问性”分组。
- 中英文使用清晰标签切换，并显示缺失数量。
- 年份选择使用“最新、指定、全部、访客选择”分段控件；指定年份后才显示年份下拉框。
- 长表单底部固定“应用”及保存状态，不遮挡最后一个字段。

## 6. 栏目与页面树

- 栏目和页面使用不同图标与文字标签。
- 同级拖动改变顺序，拖入栏目改变父节点。
- 拖动前后都由服务端验证循环和最大深度。
- 每个节点显示发布、草稿、翻译和隐藏状态。
- 行尾菜单提供复制、移动、隐藏、SEO 和回收站。
- 新增栏目与新增页面使用不同动作，不让用户猜测节点类型。
- 删除有子项的栏目时使用专门对话框选择子项处理策略。

## 7. 组件库

- 分类：新闻、通用内容、协会数据、布局。
- 支持名称、功能和关键词搜索。
- 组件卡片显示图标、名称、简短用途和可用页面。
- 拖动或点击添加；点击添加时插入当前选中组件之后。
- 最近使用和页面模板属于后续增强，不进入首期核心。

## 8. 新闻发布中心

- 列表支持搜索、状态、栏目、年份和翻译完整度筛选。
- 新建新闻后进入新闻编辑器，标题区固定，正文组件可排序。
- 中文和英文共享发布日期、年份、栏目、标签和状态。
- 发布按钮打开发布检查摘要，不直接无提示发布。
- 年份显示为清晰字段；默认随发布日期计算，手动覆盖时显示说明。
- 新闻预览与页面预览使用同一设备宽度切换。

## 9. 媒体库与拖动上传

- 空闲状态显示拖放区域、支持格式和大小限制。
- 上传项逐个显示进度、处理、完成或失败。
- 多文件中一个失败不影响其他文件。
- 上传成功后自动选中新素材，但不在用户确认前替换原组件媒体。
- 媒体详情显示尺寸、格式、替代文字、引用位置和派生版本。
- 裁剪采用组件目标比例预览，不修改原图。

## 10. 自动保存与反馈

保存状态位于顶栏：

- `正在保存…`
- `已保存于 10:36`
- `存在冲突`
- `保存失败，重试`

普通成功不弹出干扰性通知。发布、回退、永久删除等关键动作使用明确结果通知，并提供查看记录或恢复入口。

## 11. 错误、空状态和加载

- 字段错误显示在对应字段下方，并在抽屉顶部给出错误数量。
- 发布检查以可点击列表定位到具体页面和组件。
- 页面无组件时显示“从组件库添加”的引导，不显示空白画布。
- 新闻筛选无结果时保留筛选条件并提供清除按钮。
- 数据加载使用与最终布局相近的骨架，不用全屏旋转图标。
- 网络断开时保留未保存本地变更，恢复后让用户决定重试。

## 12. 确认和危险动作

需要确认：

- 发布和回退。
- 撤回正式新闻。
- 删除含子项栏目。
- 永久删除媒体或用户。
- 修改已发布页面路径。

不需要确认：普通保存、组件排序、切换语言和进入预览。组件删除可以通过短时撤销条恢复，减少确认弹窗。

## 13. 响应式后台

- 最佳宽度：1440px 及以上。
- 最低完整宽度：1280px。
- 1024-1279px：只允许一个抽屉打开，画布默认平板宽度。
- 小于 1024px：提供内容查看、简单文本修订和发布检查；复杂页面拖动提示转到桌面完成。

## 14. 前台组件一致性

- 后台画布和正式前台使用同一个组件渲染器或同一配置契约。
- 后台可以省略耗时动画，但内容、顺序、图片比例和响应式断点必须一致。
- 前台视觉仍遵循 HKBA 官网品牌设计，不把后台星系视觉强行复制到每个公开页面。

## 15. 可访问性

- 达到 WCAG 2.2 AA 的颜色对比和键盘操作目标。
- 焦点样式清晰且不只依赖浏览器默认边框。
- 抽屉打开后正确管理焦点；关闭后返回触发控件。
- 拖放有键盘替代；状态有文字；图标有可访问名称。
- 富文本标题层级和图片替代文字在发布检查中验证。

## 16. UI 验收快照

交付时至少保留以下视图的视觉回归快照：

- 星系中心：正常、草稿、错误和无权限状态。
- 页面工作室：默认、左右抽屉、专注模式和小屏单抽屉。
- 新闻编辑器：中文完整、英文缺失和发布检查失败。
- 媒体库：空状态、多文件上传、失败和引用详情。
- 前台组件：桌面、平板、手机及长文本。
