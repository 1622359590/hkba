# 會員身份顯示與排序控制設計

## 目標

擴展現有會員圖片控制 HTML 原型，讓編輯者可以按協會身份決定顯示哪些會員，並調整身份組別的展示優先級。此階段仍為獨立 HTML 原型，不修改 CMS 後端或正式前台。

## 數據基礎

會員資料已有 `group` 身份字段，可使用的組別為：

1. 榮譽主席（`honorary_chairman`）
2. 聯席會長（`co_chairman`）
3. 副主席（`vice_chairman`）
4. 秘書長（`secretary_general`）
5. 大使（`ambassador`）
6. 行業專家（`industry_expert`）

## 屬性面板

在「內容」與「圖片顯示」之間增加「顯示成員」區：

- 頂部顯示目前已啟用的身份數量。
- 每個身份為一行，包含拖動手柄、啟用勾選框、身份名稱和會員人數。
- 每行可直接拖動排序，並提供上下移動按鈕作為鍵盤與精確操作的替代方式。
- 提供「全部顯示」操作，一次重新啟用所有身份。
- 至少保留一個啟用身份；嘗試關閉最後一個身份時保持原狀並顯示簡短提示。

## 排序規則

- 預覽先按照身份列表的當前順序排列會員。
- 未啟用身份的會員不渲染。
- 同一身份內保留原始會員順序，原型不加入逐人拖動。
- 預設順序為：榮譽主席、聯席會長、副主席、秘書長、大使、行業專家。
- 恢復預設會同時恢復全部身份、預設身份順序和既有圖片顯示設定。

## 預覽表達

- 每張會員卡片增加低干擾的身份標籤，方便確認排序結果。
- 身份篩選或排序後，會員網格即時更新。
- 會員圖片大小、比例、裁剪位置和列數控制保持不變。
- 原型使用 6 位示例會員，每個身份各一位，以便清楚驗證完整排序。

## 驗收標準

- 可啟用或停用任意身份，但不能停用最後一個身份。
- 可使用上下按鈕改變身份優先級，預覽順序同步更新。
- 「全部顯示」和「恢復預設」行為明確。
- 每位會員卡片顯示身份標籤。
- 原有圖片控制和響應式佈局繼續正常工作。
