# 首页 HKBA 内部光带扫描字标设计

## 目标

将首页 Hero 中的 `HKBA` 主标题升级为具有专属科技感的动态字标。字形需稳定、清晰且符合行业协会的专业形象，动画负责强化品牌识别，不改变标题内容、按钮、统计数据或页面信息结构。

## 已确认的视觉方向

- 字体采用宽体未来科技风格，优先使用 Oxanium 700，并通过项目字体加载机制本地化或由 Next.js 管理。
- `HKBA` 使用固定字形轮廓，动画过程中不扭曲、不抖动、不切割字形。
- 字形底色为深蓝，外轮廓为浅蓝白描边，保持暗色 Hero 中的清晰对比。
- 颜色沿用现有蓝色与青色品牌体系，不引入新的强调色。
- 英文副标题 `Hong Kong Blockchain Association` 保持原有内容与位置，只校准字体搭配和字距。

## 扫描动画

- 一条细扫描线从字标顶部持续移动到底部。
- 扫描线位置是所有字内效果的唯一时间轴。
- 扫描线经过的字母内部同步出现蓝白亮度带。
- 亮度带附近显示细密横向扫描纹理，纹理与扫描线同步向下移动。
- 字形轮廓和几何位置全程固定，不使用故障抖动、水平切片或形变。
- 每次扫描约 3.4 秒，持续循环。循环重置需要柔和，避免明显跳帧。
- 动画只改变颜色、透明度和绘制位置，不触发页面布局变化。

## 组件与样式边界

- 保留 `HomeMockupSections.tsx` 中现有 Hero 结构、语义化 `h1` 和文案。
- 字标可拆分为一个小型展示组件，使基础文本、内部光带、纹理层和扫描线职责清晰。
- 动画样式归入现有首页 Hero 样式体系，不影响其他使用 `.hero-title` 的页面。
- 移动端保留完整字标，并按视口缩放字号；扫描速度不因屏幕尺寸改变。

## 无障碍与降级

- 页面中只保留一个可访问的 `HKBA` 标题，其他动画复制层必须对辅助技术隐藏。
- `prefers-reduced-motion: reduce` 下停止循环，将扫描位置固定在字标中部，保留静态科技质感。
- 文字与背景对比度满足大字号文本至少 3:1。
- 动画不得产生高频闪烁，不使用快速明暗反转。

## 验收标准

1. 桌面 Chrome 中扫描线和字内亮度带从顶部到底部严格同步。
2. `HKBA` 字形在整个动画周期中不发生位移、扭曲或切片。
3. 动画持续循环，单次周期约 3.4 秒，循环衔接无明显跳变。
4. 英文副标题、两个行动按钮和统计数据布局保持不变。
5. 鼠标交互不影响扫描动画。
6. 减少动态效果模式下动画静止，标题仍保持清晰完整。
7. 桌面与移动端均无溢出、裁切或布局偏移。
8. 前端相关测试、TypeScript 检查和生产构建通过。

## 测试策略

- 为字标展示状态建立纯函数或样式契约测试，覆盖默认动画和减少动态效果降级。
- 使用浏览器验证扫描线与内部光带的同步位置、循环位移和字形稳定性。
- 在桌面宽度和移动端宽度下进行视觉检查。
- 运行现有前端回归测试与生产构建。
