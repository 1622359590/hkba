# 會員名錄圖片控制 HTML 原型設計

## 目標

為工作室內的「會員名錄」組件提供一個獨立 HTML 原型，展示如何在右側屬性面板統一放大會員圖片，並即時調整圖片呈現方式。原型不連接後端、不修改現有 CMS 數據。

## 原型範圍

- 左側模擬工作室畫布，顯示 6 張會員卡片。
- 右側保留現有屬性面板語言，新增「圖片顯示」設定區。
- 頭像大小使用滑桿控制，範圍為 64–140px，預設 96px。
- 圖片比例提供「正方形」與「直向 4:5」。
- 裁剪位置提供「置中」與「靠上」，映射到統一的 `object-position`。
- 每行列數提供 2、3、4 列選項。
- 所有設定只作用於當前會員名錄組件，並在畫布中即時預覽。
- 提供「恢復預設」操作。

## 視覺方向

延續現有工作室的淺色屬性面板和深色會員卡片。圖片比現狀更突出，卡片保持乾淨，不增加逐張圖片的複雜控制。選中組件使用青色描邊，滑桿數值直接顯示像素。

## 交互與狀態

HTML 原型使用原生 JavaScript 和 CSS 變量更新預覽，不依賴框架。控件變更立即更新卡片網格；刷新頁面後恢復預設值。原型在窄屏下將屬性面板移到畫布下方。

## 驗收標準

- HTML 文件可直接在瀏覽器打開。
- 頭像滑桿、比例、裁剪位置和列數均能改變預覽。
- 64px 到 140px 之間不出現卡片內容溢出。
- 原型清楚表達未來接入 CMS 時所需的組件級設定。
