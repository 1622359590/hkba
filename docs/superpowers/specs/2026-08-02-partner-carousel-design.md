# 合作伙伴自动轮播组件设计

## 目标

将“关于协会”页面的合作伙伴展示改为可持续、缓慢自动播放的横向轮播，同时保留自然的手动浏览能力。后台继续使用统一的合作伙伴资料库，并允许页面编辑者通过“合作伙伴”组件配置展示行为。

## 范围

本次改动包含：

- 为前台提供可复用的合作伙伴轮播组件。
- 将“关于协会”页面的合作伙伴区域切换为默认慢速自动轮播。
- 扩展页面搭建器中的 `association.partners` 组件配置。
- 继续从现有会员管理功能读取合作伙伴名称、Logo、官网、分组、排序和启用状态。
- 补充组件配置与核心交互测试。

本次不建立第二套合作伙伴数据，不在页面组件内重复录入合作伙伴资料，也不引入第三方轮播依赖。

## 数据与后台维护

合作伙伴资料仍以现有会员管理模块为唯一数据源。资料更新后，所有引用合作伙伴组件的页面同步使用最新数据。

页面搭建器中的“合作伙伴”组件负责展示配置：

- 变体：Logo 墙、卡片、自动轮播。
- 分组筛选：沿用现有 `group` 配置。
- 自动播放：开或关；自动轮播变体默认开启。
- 速度：慢、标准、快；默认慢。
- 方向：向左或向右；默认向左。
- 悬停暂停：开或关；默认开启。

现有未配置新增字段的页面使用上述默认值，保证向后兼容。

## 前台组件结构

新增一个可复用的客户端轮播组件，由“关于协会”页面和 `association.partners` 区块渲染器共同使用。组件接收已筛选、已排序的合作伙伴列表以及播放配置，不负责请求或修改后台数据。

组件使用原生横向滚动容器，并在内容确实溢出时复制一组项目形成无缝轨道。动画由 `requestAnimationFrame` 缓慢推进 `scrollLeft`，跨过一组内容宽度时校正到对应位置，避免可见跳动。

当内容宽度未超过容器宽度时，组件保持静态，不复制项目、不启动动画。

## 交互规则

- 默认缓慢向左自动滚动。
- 鼠标悬停、组件内元素获得键盘焦点、用户拖动或触控滚动时暂停。
- 用户停止交互后短暂延迟恢复自动播放，避免与惯性滚动争抢控制。
- 支持鼠标拖动、触摸滑动、触控板和横向滚轮。
- 拖动超过点击阈值时抑制随后的链接点击，轻点或轻击仍正常打开合作伙伴官网。
- 两侧使用轻微渐隐提示横向仍有内容，系统滚动条在视觉上隐藏但滚动能力保留。
- 组件卸载、列表变化或尺寸变化时正确清理动画帧与事件状态。

## 无障碍与响应式

- 遵循 `prefers-reduced-motion: reduce`：关闭自动播放，保留手动滚动。
- 键盘焦点进入轮播后暂停，链接保留清晰的焦点样式。
- 复制出来的第二组内容不重复进入辅助技术阅读顺序，也不产生重复的可聚焦链接。
- 桌面端和移动端使用同一横向轨道；卡片宽度通过响应式 CSS 调整。
- 轮播区域提供描述性标签，便于辅助技术识别其用途。

## 错误与边界处理

- 无合作伙伴数据时沿用现有空状态。
- Logo 加载失败时沿用首字母占位表现。
- 只有一项或内容不溢出时不自动播放。
- 页面切到后台、窗口失焦或组件不可见时停止推进，恢复可见后再继续。
- 非法或缺失的速度、方向配置回退到安全默认值。

## 验证

自动化检查覆盖：

- `association.partners` 新配置字段的注册、默认值与校验。
- 旧页面数据缺少新增字段时仍能正常渲染。
- 数据筛选和排序仍来自统一合作伙伴资料库。
- 不溢出时不启动循环，溢出时能无缝复位。
- 悬停、焦点、拖动与减少动态效果均会暂停自动播放。
- 拖动不会误触链接，正常点击仍可访问官网。

手动检查覆盖桌面鼠标、触控板、移动端触摸、窗口缩放，以及“关于协会”页面和页面搭建器预览效果。

## 完成标准

“关于协会”页面的合作伙伴区域能够自动缓慢无缝轮播，并支持手动拖动与悬停暂停；后台可通过统一会员资料维护内容，并可在页面搭建器中配置轮播模式、速度、方向和暂停行为；现有合作伙伴页面与旧配置保持兼容。
