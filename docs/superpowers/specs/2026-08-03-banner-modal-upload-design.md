# Banner 中央弹窗与图片上传设计

## 目标

将 Banner 管理页的新增与编辑表单从页面内展开改为页面中央悬浮弹窗，并将图片字段改成上传交互。管理员可以点击选择图片或将图片拖入上传区；上传成功后图片自动进入媒体库，并将返回的公开图片地址写入现有 Banner 数据。界面不再提供图片 URL 输入框。

## 已确认交互

- 点击“新增”打开中央悬浮弹窗，不使用左侧抽屉，也不挤压 Banner 列表。
- 编辑现有 Banner 使用同一个弹窗，并显示当前图片预览。
- 弹窗打开时保留后台列表作为背景，叠加半透明遮罩并禁止背景交互。
- 点击遮罩、点击右上角关闭按钮或按 `Escape` 可以关闭；保存或上传进行中时禁止误关闭。
- 图片区支持点击选择和拖拽单张图片上传。
- 上传图片使用统一媒体接口 `/api/admin/media/uploads`，因此素材会同步进入媒体库。
- 上传成功后显示横幅比例预览、文件名以及“更换”“移除”操作。
- 不显示图片 URL 输入框。Banner 表仍继续保存 `image_url`，由上传接口返回的媒体公开 URL 自动回填。
- 底部操作区固定显示“取消”和“保存 Banner”，并提示“上传的图片会自动进入媒体库”。

## 弹窗布局

弹窗位于视口中央，桌面端最大宽度约 `760px`，最大高度不超过视口，表单内容区内部滚动。结构如下：

1. 标题栏：`BANNER CONTENT` 眉题、`新增 Banner` 或 `编辑 Banner` 标题、关闭按钮。
2. 图片上传区：置于表单最上方，默认显示拖拽说明、支持格式和建议尺寸；有图片时切换为预览状态。
3. 内容表单：标题、副标题和描述保持繁中/英文双语字段；链接 URL、视频 URL、排序和启用状态保留。
4. 固定页脚：媒体库提示、取消按钮、保存按钮。

窄屏下弹窗保留边距，双语两列字段改为单列，按钮仍保持可操作。

## 组件边界

### Banner 编辑弹窗

Banner 页面负责弹窗开关、创建/编辑状态、表单数据、保存与列表刷新。弹窗需要提供正确的 `role="dialog"`、`aria-modal`、标题关联和关闭行为，并在打开后锁定页面滚动。

### Banner 图片上传字段

新增一个只接收图片的上传字段，负责：

- 隐藏文件选择器和点击触发；
- 拖拽进入、离开和释放状态；
- 文件类型与单文件校验；
- 将文件以 `multipart/form-data` 上传到媒体库接口；
- 读取响应中的媒体 `url` 与 `originalFilename`；
- 上传中、成功、失败、替换和移除状态；
- 将公开 URL 通过 `onChange` 回填给 Banner 表单。

该字段不暴露手动 URL 编辑能力，也不接受 PDF。

## 数据流

1. 用户选择或拖入图片。
2. 前端立即校验是否为单张受支持图片。
3. 前端 POST 到 `/api/admin/media/uploads`。
4. 后端创建媒体库记录并返回 `asset`。
5. 前端读取 `asset.url`，更新 `form.image_url` 并显示预览。
6. 用户点击保存后，沿用现有 `/api/banners` 或 `/api/banners/:id` 请求保存 Banner。

图片上传与 Banner 保存保持两个清晰阶段：上传失败不会提交 Banner；Banner 保存失败时保留弹窗和已上传图片，方便用户重试。

## 错误与状态

- 拖入多个文件时只拒绝并提示“每次只能上传一张图片”，不静默选择第一张。
- 非图片文件显示格式错误，不发送上传请求。
- 上传中禁用选择、更换、移除、关闭和保存操作，并显示进度文案。
- 上传失败在上传区内显示错误，保留原图片（编辑场景）或空状态（新增场景）。
- 保存失败保留所有表单内容并通过现有 Toast 显示错误。
- 关闭未保存弹窗时本次表单修改被丢弃；本期不增加二次确认。

## 可访问性

- 弹窗具备语义化对话框属性和明确标题。
- 打开弹窗后焦点进入关闭按钮或首个表单控件，关闭后焦点返回触发按钮。
- 支持 `Escape` 关闭。
- 拖拽区同时是可键盘触发的上传控件，不能只有拖拽路径。
- 上传错误使用 `role="alert"`，上传状态使用 `aria-live`。

## 测试与验收

- 新增按钮和空状态按钮均打开中央弹窗。
- 编辑按钮打开同一弹窗并正确回填现有数据和图片。
- 点击选择与拖拽图片走同一上传函数。
- 上传请求调用媒体库接口，成功后回填 URL 并显示预览。
- 页面不存在图片 URL 文本输入框。
- 非图片、多文件和上传失败有明确错误。
- 上传或保存过程中不会误关闭弹窗或重复提交。
- 保存成功关闭弹窗、刷新列表并显示成功提示。
- 键盘关闭、焦点与窄屏布局正常。

## 不在本次范围

- 不修改 Banner 数据表为媒体 ID 外键。
- 不在弹窗内增加完整媒体库选择器。
- 不增加图片裁剪器或焦点位置编辑器。
- 不修改 Banner 前台展示逻辑。
