# HKBA 组件目录与配置规范

日期：2026-07-15
关联主设计：[HKBA 轻量页面构建后台总设计](./2026-07-15-hkba-lightweight-page-builder-design.md)

## 1. 组件契约

每个组件必须注册以下信息：

- `type`：稳定唯一标识，例如 `news.grid`。
- `version`：配置 schema 版本。
- `category`：`news`、`content`、`association` 或 `layout`。
- `schema`：字段、类型、默认值、长度、必填和枚举限制。
- `allowedPageTypes`：允许出现的页面类型。
- `renderer`：正式前台渲染器。
- `previewRenderer`：后台画布预览器。
- `migrations`：旧配置升级到新版本的纯函数。
- `dataResolver`：需要查询新闻、成员等内容时使用的受控查询器。

通用字段：

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `id` | string/integer | 组件实例 ID；新表可使用文本 UUID，现有实体保留 SQLite 整数 ID |
| `type` | string | 组件类型 |
| `version` | integer | schema 版本 |
| `sortOrder` | integer | 页面内顺序 |
| `isVisible` | boolean | 是否显示 |
| `anchorId` | string? | 页面锚点，页面内唯一 |
| `contentZh` | object | 中文配置 |
| `contentEn` | object | 英文配置 |
| `settings` | object | 不随语言变化的显示设置 |

组件样式只能从注册表提供的变体中选择。首期不接受任意 CSS、HTML 和脚本。

## 2. 新闻展示组件

所有新闻展示组件共享以下查询设置：

| 字段 | 取值 |
| --- | --- |
| `yearMode` | `latest`、`specific`、`all`、`visitor-select` |
| `year` | 四位整数；仅 `specific` 时必填 |
| `categoryIds` | 新闻栏目 ID 数组；空数组表示全部 |
| `tagIds` | 标签 ID 数组 |
| `limit` | 1-24 |
| `sort` | `newest`、`oldest`、`manual-featured` |
| `showYearFilter` | boolean |
| `showMoreLink` | boolean |
| `moreLinkTarget` | 页面 ID 或受验证的站内路径 |

年份规则：优先使用新闻的 `displayYear`，否则使用 `publishedAt` 所在年份。`latest` 指数据库中存在已发布新闻的最大年份，不等同于服务器当前年份。

### 2.1 新闻卡片 `news.grid`

- 用途：首页、新闻栏目页和专题页。
- 变体：两列、三列、四列、首项加大。
- 字段：标题、说明、年份模式、栏目、数量、图片比例、显示摘要、显示日期、更多链接。
- 空状态：后台显示“当前筛选没有新闻”；前台默认隐藏整个组件，也可配置显示空状态文案。

### 2.2 新闻列表 `news.list`

- 用途：新闻中心主列表和年度列表。
- 变体：紧凑列表、缩略图列表、时间轴。
- 支持前台年份及栏目筛选、分页或加载更多。
- 分页参数必须进入 URL，允许分享和浏览器返回。

### 2.3 焦点新闻 `news.featured`

- 一个主新闻加 2-4 个次要新闻。
- 来源可为自动最新、指定新闻或后台置顶集合。
- 指定新闻被撤回后，发布检查要求管理员替换或允许自动回退到最新新闻。

### 2.4 年度归档 `news.archive`

- 按年份列出新闻数量和条目。
- 默认只显示包含已发布新闻的年份。
- 支持折叠年份、年度标签或时间线变体。

### 2.5 分类标签 `news.category-tabs`

- 在组件内切换新闻栏目。
- 最多展示 8 个一级标签；更多栏目使用下拉选择。
- 切换应更新组件查询状态，不刷新整页。

### 2.6 相关新闻 `news.related`

- 只允许用于新闻详情模板。
- 默认按共同栏目和标签计算，排除当前新闻。
- 可设置 2-6 条和卡片或列表变体。

## 3. 新闻正文组件

新闻正文使用 `NewsBlock`，顺序可拖动：

### 3.1 标题区 `news.header`

- 标题、摘要、作者、发布日期、显示年份、栏目、标签和封面。
- 每篇新闻只有一个标题区，不允许删除，只能修改。

### 3.2 富文本 `content.rich-text`

- 支持段落、二至四级标题、有序/无序列表、链接、加粗和斜体。
- 不允许内联样式、脚本、iframe 和任意 HTML。
- 粘贴内容时清理外部样式。

### 3.3 单图 `media.image`

- 媒体 ID、替代文字、图注、宽度变体和对齐。
- 内容图片默认要求替代文字；装饰图片必须明确标记。

### 3.4 图集 `media.gallery`

- 2-20 张图片，可拖动排序。
- 变体：网格、轮播、灯箱。
- 每张图片可以有独立图注和替代文字。

### 3.5 视频 `media.video`

- 允许受支持的视频平台 URL 或媒体库视频文件。
- 必须配置封面；可选字幕文件。

### 3.6 引用 `content.quote`

- 引用正文、来源姓名、职务和可选头像。

### 3.7 附件下载 `content.downloads`

- 文件、显示名称、文件类型和可选说明。
- 前台显示文件大小和格式。

### 3.8 相关链接 `content.links`

- 站内页面或经过验证的外部 URL。
- 外部链接明确显示外部跳转标识。

## 4. 通用页面组件

### 4.1 主视觉 `content.hero`

- 标题、副标题、背景媒体、主要按钮、次要按钮和遮罩强度。
- 变体：全宽、左对齐、居中、图文分栏。
- 背景图片推荐 16:9，最低 1600×900。

### 4.2 图文区 `content.image-text`

- 标题、正文、图片、按钮和图片位置。
- 变体：左右双栏、窄正文、重点提示。

### 4.3 CTA `content.cta`

- 标题、说明、按钮和背景变体。
- 主要用于加入协会、联系和活动报名入口。

### 4.4 FAQ `content.faq`

- 问答数组，可排序。
- 前台使用可访问的折叠面板并输出 FAQ 结构化数据。

### 4.5 数据统计 `content.stats`

- 2-6 个统计项：数值、单位、标签和说明。
- 动画只作为渐进增强，不能影响内容读取。

### 4.6 图片画廊与视频区块

- 复用新闻正文的媒体组件，但允许不同页面宽度变体。

## 5. 协会数据组件

### 5.1 理事成员 `association.board`

- 来源为结构化成员数据，不把人物信息复制进页面。
- 筛选：届次/年份、角色、状态。
- 显示：头像、姓名、职务、简介和社交链接。

### 5.2 会员名录 `association.members`

- 筛选：会员类型、行业和首字母。
- 首期只展示公开字段；联系信息默认不公开。

### 5.3 合作伙伴 `association.partners`

- 筛选伙伴类别；变体为 Logo 墙、卡片和轮播。
- Logo 要求透明背景优先，并设置统一视觉框。

### 5.4 发展历程 `association.timeline`

- 年份、标题、说明、图片和链接。
- 支持顺序和倒序；年份为四位整数。

### 5.5 资源下载 `association.resources`

- 文件、年份、类别、语言和说明。
- 支持年份及类别筛选。

### 5.6 联系方式 `association.contact`

- 地址、邮箱、电话、办公时间、地图链接和社交媒体。
- 敏感配置从站点设置引用，不在多个页面重复维护。

## 6. 布局组件

- `layout.section`：页面区段，控制允许的宽度和背景变体。
- `layout.columns`：一至三栏；移动端固定堆叠。
- `layout.grid`：二至四列卡片网格。
- `layout.tabs`：2-8 个标签，不允许嵌套标签页。
- `layout.accordion`：可访问的折叠内容。

布局组件最多嵌套两层，防止后台树和响应式行为变得不可理解。

## 7. 组件操作

每个组件实例支持：

- 添加、复制、拖动排序、隐藏和移入草稿回收区。
- 中英文切换和翻译完整度显示。
- 从媒体库选择或拖动上传。
- 查看数据来源和当前筛选条件。
- 预览桌面、平板和手机。
- 重置为默认配置。

组件复制只复制配置和媒体引用，不复制新闻、成员等结构化内容。

## 8. 组件质量门槛

每个新增组件必须具备：

- schema 单元测试。
- 中文、英文、空数据和长文本示例。
- 三个响应式宽度的渲染测试。
- 图片缺失、链接无效和数据查询失败状态。
- 迁移测试或明确声明初始版本不需要迁移。
- 后台预览与正式前台渲染的关键字段一致性测试。
